# Список задач

Тестовое задание для стажировки. Сделали веб-приложение, в котором можно вести личный список дел и видеть прогресс.

[Открыть рабочий сайт на GitHub Pages](https://aezakmi301199.github.io/task-test/)

## Что реализовали

| Пункт задания | Как работает |
| --- | --- |
| Добавление задачи | Введите название и нажмите «Добавить» или Enter. Форма отклоняет пустые названия и строки из одних пробелов. |
| Отметка выполнения | Флажок отмечает задачу выполненной. Повторное нажатие снимает отметку. Счётчик и индикатор прогресса обновляются сразу. |
| Удаление задачи | Кнопка × удаляет выбранную задачу и обновляет счётчик. |
| Сохранение после обновления страницы | После каждого изменения приложение записывает список и статусы в `localStorage`. При открытии страницы данные восстанавливаются в том же браузере. |

## Как сделали

- **React и TypeScript** — интерфейс, типы задач и параметры компонентов.
- **MobX** — состояние списка, операции над задачами и вычисление числа выполненных.
- **MUI** — форма, кнопки, флажки, индикатор прогресса и тема.
- **Feature-Sliced Design** — структуру проекта разделили на `app` (запуск и тема), `pages/tasks` (экран списка), `features/add-task` (форма добавления) и `entities/task` (модель и сохранение задач).
- **Vite и GitHub Actions** — проверяем типы, собираем сайт и публикуем его на GitHub Pages при обновлении ветки `main`.

## Как проверили

На опубликованном сайте добавили задачу через Enter, отметили её выполненной и обновили страницу. Задача и отметка сохранились. Затем удалили задачу и снова обновили страницу, чтобы убедиться, что она не появилась в списке. Проверка типов и сборка прошли успешно.

## AI-инструменты

Использовали **OpenAI Codex**. С его помощью собрали интерфейс, реализовали логику списка и сохранение в браузере, перенесли исходники на TypeScript и настроили публикацию на GitHub Pages. Codex также запустил проверку типов и сборку и проверил четыре сценария в браузере.

## Локальный запуск

Нужны Node.js 22.12+ и pnpm 10.

```sh
pnpm install --frozen-lockfile
pnpm dev
```

Откройте адрес, который Vite выведет в терминале. Команда `pnpm typecheck` проверяет типы, `pnpm build` проверяет типы и собирает сайт в `dist/`, а `pnpm preview` запускает собранную версию локально.
