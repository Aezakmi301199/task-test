# Список задач

Тестовое задание для стажировки.

## Итоговый результат

- **Добавление задач.** Новую задачу можно добавить кнопкой «Добавить» или клавишей Enter. Пустые названия отклоняются.
- **Отметка выполнения.** Флажок меняет статус задачи, а счётчик показывает, сколько задач выполнено.
- **Удаление задач.** Кнопка × удаляет выбранную задачу из списка.
- **Сохранение после обновления.** Задачи и их статусы восстанавливаются из `localStorage` того же браузера.

## Запуск

Нужны Node.js 22.12+ и pnpm 10.

```sh
pnpm install
pnpm dev
```

Vite выведет адрес в терминале. Команда `pnpm typecheck` проверяет типы. Команда `pnpm build` проверяет типы и собирает сайт в `dist/`, а `pnpm preview` запускает эту сборку локально.

## Стек и структура

Исходники написаны на TypeScript. React отображает интерфейс, MobX хранит список и вычисляет число выполненных задач, MUI предоставляет компоненты и тему. Проект использует Feature-Sliced Design. Слои импортируют нижележащие слайсы через их публичные `index.ts`.

- `app` запускает React и подключает тему MUI.
- `pages/tasks` собирает экран со списком и прогрессом.
- `features/add-task` содержит форму и обработку ввода.
- `entities/task` содержит MobX-хранилище и работу с `localStorage`.
